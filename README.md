# 🤖 Robotics Predictive Maintenance with Deep Learning (LSTM)

This project focuses on the predictive maintenance of robotic systems by analyzing thermal data. Using Machine Learning and Deep Learning, it identifies overheating patterns to prevent hardware failure.

### 🌟 Key Highlights:
- **Dataset:** 500 rows of synthetic sensor data (Temperature, Vibration, Work Hours).
- **Model:** LSTM (Deep Learning) with **97% accuracy**.
- **Insights:** Identified that high heat (>46°C) and vibration (>3.2) are the primary causes of failure.

###  **Tech Stack**
**Language**: Python (Pandas, NumPy, Scikit-Learn, TensorFlow)

**Database**: SQL

**Visualization**: Power BI

### 🛠️ How to run:
1. Run `data_generation.py` to create the dataset.
2. Run `robot_analysis.py` for data visualization.
3. Run `deep_learning_model.py` to train and test the AI.
